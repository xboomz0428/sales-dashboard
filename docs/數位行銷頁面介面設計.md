# 數位行銷頁面 介面設計（手機優先・老花友善）

設計畫布（可在手機上點開、四頁可互相切換）：https://claude.ai/artifact/PyS52L2BwYLFaCb9tS4hnH
對應規劃：`docs/Google廣告_GA_GSC串接規劃.md` 第 6.1 節。
狀態：設計稿，尚未實作。範圍：好漢草品牌（示意數字請以平安包、足沐湯浴包為主）。

## 設計目標

1. **老花也能用**：不戴眼鏡、手機拿在正常距離就能讀。
2. **手機滿版操作**：單手拇指可達，所有主要操作在畫面下半部；桌機只是放大版。
3. **一眼看懂**：每頁回答一個問題，不塞表格。

## 四個頁面

| 頁 | 回答的問題 | 內容 |
|---|---|---|
| ① 總覽 | 這個月廣告花了多少、划不划算？ | 本月花費（超大字）、ROAS、廣告費率燈號、官網營收、近 7 天花費／營收兩張單軸長條圖 |
| ② 廣告活動 | 哪檔廣告在賺、哪檔在燒？ | 期間切換、依花費排序的卡片（花費／轉換／每筆成本／點擊＋健康燈號＋與上月比較）、異常卡片紅框 |
| ③ 流量與搜尋 | 官網有人來嗎、Google 搜尋得到嗎？ | GA4 四個數字、來源占比橫條、GSC 三個數字、熱門搜尋字與排名升降 |
| ④ 同步與顯示設定 | 資料是新的嗎？字太小怎麼辦？ | 三個來源的同步狀態（✓／✗＋文字＋時間）、立即同步大按鈕、字級三段、高對比、LINE 推送 |

底部固定分頁列：總覽／廣告／流量／設定，每格 72px 高、圖示 30px＋文字 16px。
右上角固定「A+」56px 按鈕，一鍵進字級設定。

## 老花友善規則（實作時當驗收標準）

| 項目 | 規格 | 對應 Tailwind／CSS |
|---|---|---|
| 內文字級 | 預設 18px，可切 20／24px | 在 `<html>` 上設 `font-size`，元件全用 `rem`；設定存 `localStorage.font_scale` 並同步 `dashboard_settings` |
| 標籤最小字級 | 16px，**不得再小** | 禁用 `text-xs`（12px）、`text-sm`（14px）於本頁 |
| 重點數字 | 40px／32px／24px 三級，字重 900，`tabular-nums` | `font-variant-numeric: tabular-nums` |
| 行高 | 1.45 | `leading-relaxed` |
| 文字顏色 | 主 `#1a1f1c`、次 `#3a4540`，**不用淡灰當說明文字** | 現有 token `--ink-900`／`--ink-700`；禁 `text-gray-400`、`text-gray-500` |
| 卡片邊框 | 1.5px `#d5d7cb`，高對比模式 2px `#1a1f1c` | `--line-strong` |
| 可點區域 | 最小 56px 高（次要按鈕 48px），間距 ≥ 12px | `min-h-14` |
| 狀態表達 | 顏色＋圖示＋文字三者並用（「健康」「需注意」「失敗」） | chip 元件：綠 `#d4f5e5/#0b5536`、黃 `#fff1d6/#8a4b00`、紅 `#ffe6de/#9b1c1c` |
| 圖表 | 單一數列、單一軸、不做雙軸；只標最高與今天兩個數字；長條頂端 4px 圓角 | 沿用 Recharts 或純 div 長條 |
| 圖表顏色 | 花費 `#10744a`、營收 `#0369a1`（已跑色盲與對比驗證通過） | — |
| 深色模式 | 文字 `#f4f2ec`、卡片 `#1f2622`、長條顏色改用 `#46c98e`／`#81d4fa` | 沿用 `dark:` class |
| 手勢 | 不靠左右滑動切換，一律用按鈕；清單不做長按 | — |
| 安全區 | 頂部 56px 留給瀏海，底部分頁列加 `env(safe-area-inset-bottom)` | `index.css` 已有 safe-area 設定 |

## 與現有儀表板的銜接

- 新 Tab id `marketing`，分組「分析」，`TAB_DEFS` 加入後 manager／viewer 預設可見。
- 資料來源：`google_ads_daily`、`ga4_daily`、`gsc_daily`、`google_sync_log`（規劃第 5 節）；
  本月營收沿用 `useSalesData` 的官網通路篩選。
- 字級設定是全站的：做成 `useFontScale` hook，先在本頁套用，其餘分頁逐步改用 `rem`。
- 桌機版：同一組卡片改三欄 grid（`lg:grid-cols-3`），圖表加寬到 30 天，不另做桌機版面。

## 實作順序

1. `useFontScale` ＋ 設定頁（④），因為全站受益。
2. 總覽（①）：先只接 Google Ads 同步資料。
3. 廣告活動（②）。
4. 流量與搜尋（③）：待 GA4／GSC 同步上線。
